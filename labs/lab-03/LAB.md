# Lab 03

toString, equals, hashCode, nested Address, clone and instanceof.

## Run this lab
From the project root, compile all source files using the root build script for the integrated application. To run this standalone lab example, compile its Java file into a separate output directory:

```bash
javac -d /tmp/lab03-out labs/lab-03/src/main/java/lab03/Lab03Demo.java
java -cp /tmp/lab03-out lab03.Lab03Demo
```

This lab folder contains actual Java source, not only README notes. The integrated `src/main/java/minibank` application contains the user-driven MiniBank system.
